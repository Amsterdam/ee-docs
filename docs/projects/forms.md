# Forms in React

Amsterdam's preferred approach for forms uses <a href="https://reactjs.org/" target="_blank">React</a> with either HTML5 or <a href="https://react-hook-form.com/" target="_blank">React Hook Form</a>. Combining the right form strategy with accessibility, validation, and security considerations can be tricky. Therefore, we have created a repository with demos and documentation to help developers and designers choose the right approach and build forms with confidence.

You can browse the project at [https://forms.developers.amsterdam/](https://forms.developers.amsterdam/).
